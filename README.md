# VideoDock

ページ内の動画の上にアクションボタンを埋め込む Chrome 拡張機能 (Manifest V3, Chrome 114+)。

## 機能
動画にマウスを乗せると右上にツールバーが出ます（約2.5秒で自動的に隠れます）。

| ボタン | 動作 | ショートカット |
|---|---|---|
| PiP | 動画を別ウィンドウ（ピクチャインピクチャ）で表示 | `Alt+P` |
| − / 100% / ＋ | ズーム（最大8倍）。%部分クリックでリセット | `Alt+−` `Alt+＋` `Alt+0` |
| 最大化 | フルスクリーンではなく、ブラウザのウィンドウ内いっぱいに表示。`Esc` で戻る | `Alt+W` |

- `Alt + ホイール`: カーソル位置を中心にズーム
- `Alt + ドラッグ`: ズーム中の動画をパン
- `Alt + ダブルクリック`: ズームをリセット

## 仕組み
- **ズーム**: video に `transform` と、元の枠に合わせた `clip-path` を付与（親要素は変更しない）
- **最大化**: Popover API でトップレイヤーへ移動し `100vw × 100vh` に。祖先の `transform` / `z-index` / `overflow` の影響を受けない。サイト独自のUIは背面になるため、最大化中は標準コントロールを一時的に有効化
- **iframe内の動画**: 子フレームが親へ要求し、親フレームが iframe 要素自体を最大化（ユーザー操作の伝播 `navigator.userActivation` を確認し、勝手な最大化を防止）
- ズームの基準は`<video>`要素の枠ではなく、object-fit/object-positionを考慮した「映像が実際に描画されている領域」（レターボックス除外）
- 動画の検出は MutationObserver + 3秒ごとの Shadow DOM 走査

## インストール / 動作確認
1. `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」で本フォルダを選択
2. `test/index.html` を開いて確認（ローカルファイルで使うには拡張機能の詳細で「ファイルのURLへのアクセスを許可する」をON）

## 既知の制限
- PiP ウィンドウにはズームは反映されません（元映像が出ます）
- 最大化すると、その動画はページの流れから外れるためレイアウトが一時的にずれることがあります
- 最小サイズ (240×135) 未満の動画、音声のみの動画にはツールバーを出しません
- DRM (EME) 動画でも動作しますが、サイト側が PiP を禁止している場合は属性を解除して開始します
- `icons/` は `node tools/make-icons.js` で再生成できます
