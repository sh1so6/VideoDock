# VideoDock

ページ内の動画の上にアクションボタンを埋め込む Chrome 拡張機能 (Manifest V3, Chrome 116+ 推奨)。

## 機能
動画にマウスを乗せると右上にツールバーが出ます（約2.5秒で自動的に隠れます）。

| ボタン | 動作 | ショートカット |
|---|---|---|
| PiP | 動画を別ウィンドウに移す。**PiPウィンドウ内でズーム/移動できる** | `Alt+P`（PiP中は閉じる） |
| 最大化 | フルスクリーンではなく、ブラウザのウィンドウ内いっぱいに表示。`Esc` で戻る | `Alt+W` |

### 画像のPiP
画像も、ズーム・移動つきの別ウィンドウ（常に手前）で出せます。
- **開き方**: `Alt` を押しながら画像にマウスを乗せるとPiPボタンが出ます（`Alt+P` でも開けます）。設定で、トリガーのキーを任意のキー（Ctrl/Shift/`Z` など）に変更／キー不要（ホバーのたびに出す）／使わない、を選べます。画像の上なら、どのモードでも `Alt+P` で開けます。
- **操作**: ホイール（または右クリック+ホイール）でズーム、ドラッグで移動、ダブルクリックで拡大⇔戻す、`H` で操作バー、`Alt+P` で閉じる。
- 元のページの画像は動かさず、複製を表示します（GIF/アニメWebPも動きます）。再取得に失敗した画像（ホットリンク対策など）は読み込み済みの画像を静止画で表示します。
- 最上位のページ内の `<img>` が対象です（iframe内・CSS背景画像・canvas/SVGは未対応）。120px未満の小さな画像は対象外（設定で変更可）。

### PiPウィンドウでの操作
| 操作 | 動作 |
|---|---|
| 右クリックを押しながらホイール | カーソル位置を中心にズーム（最大8倍） |
| 窓の上部でホイール | 音量（既定。設定で下部と入れ替え可） |
| 窓の下部でホイール | シーク（既定。設定で上部と入れ替え可） |
| 窓の中央でホイール | 何もしない |
| ドラッグ | ズーム中の映像を移動 |
| ダブルクリック | 窓いっぱいに拡大 ⇔ 元に戻す |
| クリック / `Space` | 再生・一時停止 |
| `+` `-` `0` | 拡大・縮小・リセット |
| `←` `→` / `M` / `F` | 5秒シーク / ミュート / フィル切替 |
| `H` | 操作バーの固定表示 ⇔ 解除 |
| `⤴` ボタン | 元のタブへ戻す（ウィンドウを閉じても戻る） |

### 設定（拡張機能の「オプション」）
ツールバーの拡張機能ボタンを押すと設定ページが開きます。
- **ページ内のボタン**: 表示位置（右上/上中央/左上/右下/下中央/左下）、出すタイミング（領域に入ったら／ボタンの近くにカーソルが来たら＋範囲px）、隠すまでの時間（0=領域内にいる間は隠さない）。
PiP窓の操作バーは、ブラウザ標準ではなく VideoDock 独自のUIなので、出し方を変えられます（変更は開いているPiP窓にも即反映）。
- 出し方: 下端に近づいたときだけ（既定）/ マウスを動かすたび / 常に表示（動画に重ねる） / **動画の下に常設**（動画に重ならず、表示領域がバーの分40px縮む。`H` で出し入れ。PiP窓の初期高さもバー分だけ足す） / 表示しない（`H` で出し入れ）
- 下端の反応範囲、隠すまでの時間、PiPを開いたときのヒント表示（既定: オフ）
- ホイール操作: 上部/下部の割り当て入れ替え、範囲（窓の高さの%）、音量・シークのホイール向き反転、ズームのホイール向き反転、1ノッチあたりの音量(%)・シーク(秒)
- 表示するボタン（再生・シークバー・時間・ミュート・ズーム・タブに戻す）。隠してもキー操作は使えます

## 仕組み
- **PiP**: Document Picture-in-Picture API で別ウィンドウを開き、元の `<video>` 要素そのものをそこへ移動。ズーム/パンは PiP 側の `transform` で行うので、サイトのプレーヤー構造に影響されない。閉じると元の位置（コメントノードの目印）へ戻し、インラインstyle・`controls` も復元する。音声・DRM も元のまま。
- **フォールバック**: iframe内・http・Document PiP 非対応・失敗時は標準PiP（`requestPictureInPicture`）で開く。この場合ズームはできない。
- **最大化**: Popover API でトップレイヤーへ移動し `100vw × 100vh` に。祖先の `transform` / `z-index` / `overflow` の影響を受けない。サイト独自のUIは背面になるため、最大化中は標準コントロールを一時的に有効化。
- **iframe内の動画の最大化**: 子フレームが親へ要求し、親フレームが iframe 要素自体を最大化（`navigator.userActivation` を確認し、勝手な最大化を防止）。
- ツールバー位置は `object-fit` を考慮した「映像が実際に描画されている領域」基準。
- PiPウィンドウ自体（トップレベルの about:blank）には content script を動かさない（拡張が自動注入され、操作を横取りしたため）
- 動画の検出は MutationObserver + 3秒ごとの Shadow DOM 走査。

## インストール / 動作確認
1. `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」で本フォルダを選択
2. `test/index.html` / `test/pip-test.html` を開いて確認（ローカルファイルは「ファイルのURLへのアクセスを許可する」をON）
3. 自動テスト: `node test/cdp-pip.js [ext|direct]`。Chromeを起動し、CDPの本物の入力で `Alt+P`→右クリック+ホイールズーム→上部/下部ホイール(音量/シーク)→ドラッグ→画像PiP→PiP内`Alt+P`/「タブに戻す」で閉じる→style・controlsの完全復元→`Alt+W`/`Esc`、までをassert（失敗時は非ゼロ終了）。`ext`（既定）は `Extensions.loadUnpacked` で拡張機能として読み込み、`direct` は `content.js` をページへ直接読み込む

## 開発メモ（git / バージョン）
- 初回のみ `git config core.hooksPath .githooks` を実行すると、コミットのたびに `manifest.json` の `version`（patch）が自動で +1 されます（`tools/bump-version.js`）。
- 一時的に止める: `SKIP_BUMP=1 git commit ...`。minor/major を上げたいときは `manifest.json` を手で書き換えてステージすれば、その値が優先されます。

## 既知の制限
- PiP中は `<video>` がページから抜けるため、サイトのプレーヤー表示が空になります。React系サイトでは、PiP中に再描画されて戻し先が失われると、動画を戻せないことがあります（コンソールに警告）。
- サイトの IntersectionObserver / ResizeObserver 等が、動画の移動に反応することがあります。
- 拡張機能を PiP 中に再読み込みすると、元に戻す処理が働きません（ページを再読み込みしてください）。
- 最大化中は、その動画がページの流れから外れてレイアウトが一時的にずれることがあります。
- 最小サイズ (240×135) 未満の動画、音声のみの動画にはツールバーを出しません。
- `icons/` は `node tools/make-icons.js` で再生成できます。
