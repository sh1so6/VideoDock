右クリックを押しながらホイール = ズーム（カーソル位置が中心）。窓の上部・下部でのホイールは次の割り当てです。中央部は何もしません。

画像のPiP（ズーム・移動つきの別ウィンドウ）
キー
Alt / Ctrl / Shift / Win だけでなく、Z など任意のキーも設定できます。上の欄をクリックして、使いたいキーを押してください。
対象にする画像の最小幅 px
どのモードでも、画像の上で Alt+P を押せばPiPを開けます。画像のPiPでは、ホイール（または右クリック+ホイール）でズーム、ドラッグで移動、ダブルクリックで拡大⇔戻す。最上位のページ内の画像のみ対応します。
表示するボタン
ボタンを隠しても、キー操作（Space / ← → / + − 0 / M / F / H）は使えます。
